# tee-image-builder
This repository handles building TEE images for batch posters for different stacks (Arbitrum Nitro &amp; OP) and different TEE infrastructures (AWS Nitro, SGX, etc.).

## Setup

> **Important:** Run this once after cloning before making any commits.

```bash
.githooks/install.sh
```

This configures Git to use the repository's hooks, including protection against accidentally committing private keys.
