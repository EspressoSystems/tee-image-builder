# Integration-v3.9.2 Node Config Changes

This page documents the changes introduced in [commit](https://github.com/EspressoSystems/nitro-espresso-integration/commit/db6a95d4ef5082eb7872b2c45fc1846f4b740c62) on `integration-v3.9.2` branch which aimed at simplifying the `Node` Config by separating the `espresso-` related fields from the generic fields and grouping them together in a parent `EspressoConfig` field

To convert an old config json file to new format use this [script](./migrate-config-file.py) by running:

```bash
python3 ./migrate-config-file.py ./assets/old_config.json ./assets/config.json
```

## Summary

### node.batch-poster.espresso → node.espresso

| Original Field | New Field |
|----------------|-----------|
| `hotshot-block` | `espresso.streamer.hotshot-block` |
| `espresso-txns-polling-interval` | `espresso.streamer.txns-polling-interval` |
| `address-monitor-step` | `espresso.streamer.address-monitor-step` |
| `address-monitor-start-l1` | `espresso.streamer.address-monitor-start-l1` |

### node.batch-poster → node.espresso.batch-poster

| Original Field | New Field |
|----------------|-----------|
| `espresso-tee-type` | `espresso.batch-poster.tee-type` |
| `hotshot-url` | `espresso.batch-poster.hotshot-url` |
| `espresso-txns-resubmission-interval` | `espresso.batch-poster.txns-resubmission-interval` |
| `resubmit-espresso-tx-deadline` | `espresso.batch-poster.resubmit-espresso-tx-deadline` |
| `espresso-event-polling-step` | `espresso.batch-poster.event-polling-step` |
| `attestation-service-url` | `espresso.batch-poster.attestation-service-url` |
| `hotshot-first-posting-block` | `espresso.batch-poster.hotshot-first-posting-block` |
| `init-batcher-addresses` | `espresso.batch-poster.init-batcher-addresses` |
| `address-valid-ranges` | `espresso.batch-poster.address-valid-ranges` |
| `espresso-txns-sending-interval` + `espresso-txns-polling-interval` | **COMBINED** → `espresso.batch-poster.txns-monitoring-interval` |
| `espresso-register-service-config` | **REMOVED** (Hard coded) |
| `espresso-tx-size-limit` | **REMOVED** (Hard coded) |
| `quote-file` | **REMOVED** (Hard coded) |
| `user-data-attestation-file` | **REMOVED** (Hard coded) |

### node.espresso-caff-node → node.espresso.caff-node

- remove all `espresso-` prefixes since we are already inside an `espresso` parent block
- `hotshot-urls` → `node.espresso.caff-node.hotshot-url`

**Fields moved to `espresso.streamer`:**

| Original Field | New Field |
|----------------|-----------|
| `next-hotshot-block` | `node.espresso.streamer.hotshot-block` |
| `from-block` | `node.espresso.streamer.address-monitor-start-l1` |
| `retry-time` | `node.espresso.streamer.txns-polling-interval` |
| `address-monitor-step` | `node.espresso.streamer.address-monitor-step` |
| `dangerous.minimum-hotshot-block-num` | `espresso.streamer.dangerous.minimum-hotshot-block-num` |
